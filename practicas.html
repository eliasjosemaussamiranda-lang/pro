Vamos a practicar

Aprenderemos escribiendo código. Haz los ejercicios con calma; primero queremos que funcionen.

Tu primer proyecto

  1. Crea una carpeta para tu proyecto.
  2. Abre VS Code y selecciona Archivo → Abrir carpeta.
  3. Crea un archivo llamado index.html.
  4. Escribe la estructura del primer documento HTML, guárdalo y ábrelo en el navegador.

Ejercicio 1: preséntate

Crea un título con tu nombre, un párrafo sobre ti y una lista con tres cosas que te gusten.

<h1>Tu nombre</h1>
<p>Algo sobre ti.</p>
<ul>
  <li>Algo que te gusta</li>
</ul>

Ejercicio 2: agrega una imagen

Guarda una imagen en la carpeta de tu proyecto y muestra su nombre de archivo en src. No olvides describirla con alt.

<img src="foto.jpg"
     alt="Descripción de la foto">

Ejercicio 3: crea un enlace

Agrega un enlace a otra página usando el atributo href.

<a href="https://ejemplo.com">
  Visitar página
</a>

Ejercicio 4: un botón que responde

El botón llama una función sencilla de JavaScript cuando haces clic.

<button onclick="saludar()">
  Haz clic
</button>
<script>
  function saludar() {
    alert("Hola");
  }
</script>

Reto: crea tu primera página

Intenta hacer una página sin copiar el ejemplo completo. Debe tener:

  1. Un título y una pequeña descripción.
  2. Una imagen y una lista.
  3. Un enlace y un botón.

No importa si al principio no queda bonita. Primero hagamos que funcione; después aprenderemos CSS para mejorar su apariencia.
