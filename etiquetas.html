Conceptos Etiquetas Ejemplo

Etiquetas más usadas

Estas etiquetas sirven para organizar elementos comunes de una página HTML.

  1. <h1>, <h2>, <h3>: títulos y subtítulos; <h1> es el título principal.
  2. <p>: crea un párrafo.
  3. <img>: muestra una imagen. Usa el atributo alt para describirla.
  4. <ol>: crea una lista ordenada.
  5. <ul>: crea una lista con viñetas.
  6. <li>: representa un elemento de una lista.
  7. <strong> y <em>: indican contenido importante o enfatizado.
  8. <a>: crea un enlace a otra página o lugar del sitio.
