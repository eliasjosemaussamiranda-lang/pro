Etiquetas y estructura HTML

Las etiquetas le dicen al navegador cómo está organizado el contenido. Vamos a conocer las más útiles para empezar.

La estructura de un documento

Un archivo HTML comienza con una estructura que indica al navegador qué tipo de documento está leyendo.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>Hola mundo</h1>
  <p>Esta es mi primera página web.</p>
</body>
</html>
  • <!DOCTYPE html> indica que usamos HTML moderno.
  • <html> contiene toda la página.
  • <head> guarda información de la página, como su título.
  • <title> define el texto de la pestaña del navegador.
  • <body> contiene lo que aparece dentro de la página.
  • <h1> es el encabezado principal y <p> crea un párrafo.

Títulos

<h1> es el título principal. <h2> y <h3> organizan subtítulos.

<h1>Mi página</h1>
<h2>Una sección</h2>

Párrafos y saltos

<p> crea un párrafo. <br> hace un salto de línea, pero no debe usarse para distribuir toda la página.

<p>Estoy aprendiendo.</p>
Primera línea<br>Segunda línea

Enlaces

<a> crea un enlace. El atributo href indica adónde lleva.

<a href="https://www.google.com">
  Ir a Google
</a>

Imágenes

src indica dónde está la imagen y alt ofrece una descripción si no puede verse o para lectores de pantalla.

<img src="imagen.jpg"
     alt="Descripción de la imagen">

Listas

<ul> hace una lista con viñetas, <ol> una lista numerada, y <li> cada elemento.

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Texto importante

<strong> marca contenido importante y <em> añade énfasis.

<strong>Importante</strong>
<em>Énfasis</em>

Atributos

Los atributos agregan información a una etiqueta. Por ejemplo, en un enlace href guarda la dirección; en una imagen src indica el archivo y alt lo describe. También conoceremos class, id, style y title; no hace falta aprenderlos todos hoy.
