Etiquetas en JavaScript

JavaScript añade acciones a una página: puede guardar información, tomar decisiones y responder a los clics. Aquí veremos instrucciones básicas con ejemplos que puedes probar.

Mostrar un mensaje

console.log() escribe un mensaje en la consola del navegador, útil para revisar qué está pasando en el programa. alert() muestra una ventana emergente; úsala en ejemplos pequeños y no para cada mensaje de la página.

console.log("La página está lista");
alert("¡Bienvenido a la receta!");

Abre las herramientas de desarrollador del navegador y selecciona Consola para ver el primer mensaje.

Variables: guardar datos

const crea una variable cuyo valor no se volverá a asignar. let sirve cuando necesitas cambiar su valor. Los nombres deben explicar qué información guardan.

const nombre = "Lucía";
let puntos = 0;

puntos = puntos + 1;
console.log(nombre, puntos);

nombre conserva el texto «Lucía» y puntos cambia de 0 a 1. Usa const por defecto y let cuando el valor tenga que cambiar.

Tipos de datos y operaciones

Los textos van entre comillas, los números se escriben sin comillas y los valores true o false representan verdadero o falso. El signo + suma números y también puede unir textos.

const precio = 5;
const cantidad = 3;
const total = precio * cantidad;
const mensaje = "Total: $" + total;

console.log(mensaje);

El resultado muestra «Total: $15». Fíjate en que precio y cantidad son números, mientras que mensaje es un texto.

Tomar decisiones con if

if ejecuta instrucciones solo cuando una condición es verdadera. Puedes usar else para indicar qué hacer cuando no lo es.

const tieneEntrada = true;

if (tieneEntrada) {
  console.log("Puedes entrar");
} else {
  console.log("Necesitas una entrada");
}

Como tieneEntrada vale true, la consola muestra «Puedes entrar». Si lo cambias a false, muestra el otro mensaje.

Funciones: reutilizar instrucciones

Una función agrupa instrucciones con un nombre para poder ejecutarlas cuando se necesiten. Los valores entre paréntesis son datos que la función recibe.

function saludar(nombre) {
  return "Hola, " + nombre;
}

console.log(saludar("Mateo"));

Al llamar saludar("Mateo"), la función devuelve «Hola, Mateo». Puedes llamarla de nuevo con otro nombre sin repetir sus instrucciones.

Seleccionar un elemento de la página

document.querySelector() busca en el documento el primer elemento que coincida con el selector CSS. Usa # para buscar por id y . para buscar por class.

<p id="mensaje">Tu pedido está listo.</p>
const mensaje = document.querySelector("#mensaje");
console.log(mensaje.textContent);

El selector "#mensaje" encuentra el párrafo y textContent permite leer su texto.

Responder a un clic

addEventListener() espera un evento, como un clic, y ejecuta una función cuando ocurre. Primero prepara el botón en HTML y luego conecta su comportamiento con JavaScript.

<button id="saludar">Saludar</button>
<p id="respuesta"></p>
const boton = document.querySelector("#saludar");
const respuesta = document.querySelector("#respuesta");

boton.addEventListener("click", () => {
  respuesta.textContent = "¡Hola! Gracias por visitar.";
});

Al hacer clic, el programa cambia el texto del párrafo. Coloca el script después de esos elementos HTML o cárgalo con defer para que ya existan cuando JavaScript los busque.

Conectar JavaScript con HTML

Guarda tu programa en un archivo terminado en .js, por ejemplo script.js. Para cargarlo, agrega una etiqueta <script> al final del <body>, después de los elementos con los que va a trabajar.

<body>
  <button id="saludar">Saludar</button>
  <p id="respuesta"></p>
  <script src="script.js"></script>
</body>

El valor de src debe coincidir con el nombre y la ubicación del archivo JavaScript. Puedes abrir la consola del navegador para revisar los mensajes y errores.
