Errores comunes

Los errores son parte normal de aprender. Vamos a revisar algunos comunes y cómo empezar a buscarlos.

Etiqueta sin cerrar

Si abres un párrafo, recuerda cerrarlo.

<!-- Incorrecto -->
<p>Hola

<!-- Correcto -->
<p>Hola</p>

Nombre mal escrito

Una letra de más puede hacer que el navegador no reconozca una etiqueta.

<!-- Incorrecto -->
<titlle>Hola</titlle>

<!-- Correcto -->
<title>Hola</title>

Confundir class e id

En CSS una clase comienza con punto y un id con numeral. En HTML se escriben sin esos símbolos.

<p class="importante">Grupo</p>
<h1 id="titulo">Único</h1>

Ruta de imagen incorrecta

Comprueba que el nombre del archivo y su ubicación coincidan con el valor de src.

<img src="foto.jpg"
     alt="Mi foto">

Problemas con CSS

Revisa que el nombre de la hoja de estilos esté bien escrito y que su ruta en el enlace <link> sea correcta.

<link rel="stylesheet"
                  href="../css/base.css">

¿Cómo saber qué está pasando?

Cuando algo no funciona, no tenemos que adivinar. Las herramientas para desarrolladores del navegador permiten inspeccionar elementos, revisar estilos y encontrar algunos errores.

En Chrome o Edge puedes abrirlas con F12 o Ctrl + Shift + I. No hace falta aprenderlo todo ahora; iremos conociéndolas poco a poco.

Tranquilo: si no funciona a la primera, revisa el nombre, la ruta y las etiquetas. Cada error es una oportunidad de aprender algo nuevo.

No intentes memorizar todo

Es mejor aprender unas pocas etiquetas y utilizarlas varias veces que intentar memorizar cien en un día. Con h1, p, img, a y button ya puedes empezar a crear. Programar se aprende escribiendo código, no solo leyéndolo.
