Etiquetas en HTML

Las etiquetas organizan el contenido y le indican al navegador qué significa cada parte. Cada tarjeta explica un grupo de etiquetas y muestra un ejemplo pequeño que puedes adaptar a tu propio sitio.

La estructura de un documento

Todo archivo HTML empieza con una estructura básica. <!DOCTYPE html> indica que usamos HTML moderno; <html> contiene la página; <head> guarda información que normalmente no se ve dentro de la página; y <body> contiene el contenido visible.

El elemento <title> va dentro de <head> y define el texto de la pestaña del navegador. El atributo lang="es" indica que el idioma principal es español.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi receta favorita</title>
</head>
<body>
  <h1>Panqueques</h1>
  <p>Una receta fácil para compartir.</p>
</body>
</html>

Títulos

Los encabezados organizan el contenido por temas. <h1> es el título principal de la página; usa <h2> para las secciones y <h3> para apartados dentro de una sección. Mantén el orden para que la página sea fácil de recorrer y entender.

<h1>Mi huerta en casa</h1>
<h2>Cómo plantar tomates</h2>
<h3>Materiales necesarios</h3>

En este ejemplo, «Cómo plantar tomates» es una sección del tema «Mi huerta en casa», y «Materiales necesarios» pertenece a esa sección.

Párrafos y saltos de línea

Usa <p> para separar ideas en párrafos. La etiqueta <br> crea un salto de línea dentro del mismo párrafo; resérvala para casos como una dirección o un poema, no para separar párrafos ni crear espacio de diseño.

<p>La biblioteca abre a las nueve.</p>
<p>Recuerda devolver los libros a tiempo.</p>

<p>Calle Central 25<br>Bogotá</p>

Los dos primeros mensajes son ideas separadas, por eso tienen su propio <p>. La dirección usa <br> para continuar en la línea siguiente sin empezar otro párrafo.

Enlaces

La etiqueta <a> crea un enlace y su atributo href indica el destino. El texto entre la etiqueta de apertura y la de cierre debe explicar adónde lleva el enlace.

<a href="https://www.bibliotecanacional.gov.co/">
  Visita la Biblioteca Nacional
</a>

También puedes enlazar a otra página de tu proyecto, por ejemplo <a href="contacto.html">Contáctanos</a>. Comprueba que la dirección del atributo href sea correcta.

Imágenes

La etiqueta <img> muestra una imagen. El atributo src indica el nombre o la ruta del archivo, y alt ofrece una descripción útil si la imagen no carga o si una persona usa un lector de pantalla. <img> no necesita una etiqueta de cierre.

<img src="imagenes/huerta.jpg"
     alt="Tomates maduros creciendo en una huerta">

Guarda la imagen en la carpeta indicada por src y escribe en alt lo que realmente aparece en ella, en vez de poner solo «foto».

Listas

<ul> crea una lista con viñetas para elementos cuyo orden no importa. <ol> crea una lista numerada para pasos que sí deben seguirse en orden. Cada elemento de cualquiera de las listas se escribe con <li>.

<h3>Ingredientes</h3>
<ul>
  <li>2 tomates</li>
  <li>1 cebolla</li>
</ul>

<h3>Preparación</h3>
<ol>
  <li>Lava los ingredientes.</li>
  <li>Córtalos en trozos.</li>
</ol>

Usa una lista numerada para la preparación porque hay que seguir sus pasos en secuencia; los ingredientes pueden presentarse con viñetas.

Negrita y cursiva

<b> muestra el texto en negrita y <i> lo muestra en cursiva. Sirven para dar formato visual. Cuando quieras indicar que algo es importante, prefiere <strong>; para dar énfasis a una palabra o frase, usa <em>. Estas últimas etiquetas también comunican el significado del texto.

<p>La función tiene un <b>botón rojo</b>.</p>
<p>El museo abre <i>solo los domingos</i>.</p>
<p><strong>Importante:</strong> guarda tu trabajo.</p>
<p>Este paso es <em>muy sencillo</em>.</p>

En el ejemplo, <b> y <i> cambian la presentación; <strong> marca una advertencia importante y <em> enfatiza «muy sencillo».

Class e id

class y id son atributos que se escriben dentro de la etiqueta de apertura. Una misma clase se puede reutilizar para varios elementos; un id identifica un elemento particular de la página y debe ser único en ella.

<p class="aviso">La tienda cierra a las seis.</p>
<p class="aviso">El sábado cierra a las cuatro.</p>
<h2 id="horarios">Horarios de atención</h2>

En CSS, seleccionas la clase con un punto, como .aviso, y el id con el símbolo #, como #horarios. Usa una clase cuando varios elementos comparten un estilo y un id para señalar uno específico.

Atributos

Los atributos agregan información o configuración a una etiqueta y se escriben en la etiqueta de apertura como nombre="valor". Por ejemplo, en un enlace href guarda el destino; en una imagen src indica el archivo y alt describe la imagen. También existen class e id.

<a href="contacto.html" title="Ir a contacto">
  Escríbenos
</a>

<img src="imagenes/equipo.jpg"
     alt="El equipo reunido en la oficina">

Los atributos de cada etiqueta pueden ser distintos. Escribe sus valores entre comillas y revisa que la ruta o el texto correspondan con el archivo o destino real.
