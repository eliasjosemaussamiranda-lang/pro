Siguiente nivel

Después de aprender HTML, CSS y JavaScript, podemos conocer cómo se guarda la información que utilizan las páginas web. Antes de practicar en el computador, entendamos qué es una base de datos, cómo se relacionan sus datos y cómo una aplicación se comunica con ella.

¿Qué es una base de datos y para qué sirve?

Una base de datos es una colección organizada de información relacionada. Sirve para guardar datos de manera persistente, encontrarlos cuando hacen falta y mantenerlos actualizados sin depender de que una página esté abierta.

Una tienda puede guardar clientes, productos y pedidos; una escuela puede organizar estudiantes, carreras, materias y profesores. En lugar de repetir los mismos datos muchas veces, se pueden guardar una vez y relacionarlos.

Tablas y relaciones

En una base de datos relacional, la información se organiza en tablas. Las columnas indican qué datos se guardan (por ejemplo, nombre o fecha) y cada fila contiene los datos de un registro. Para relacionar registros, las tablas usan identificadores: una clave primaria identifica una fila, y una clave foránea guarda el identificador relacionado de otra tabla.

Las relaciones describen cuántos registros de una tabla pueden corresponder a registros de otra:

  • Uno a uno (1:1): cada registro de una tabla se relaciona con un solo registro de la otra. Ejemplo: una persona y su pasaporte vigente.
  • Uno a muchos (1:N): un registro de la primera tabla puede relacionarse con varios de la segunda, pero cada registro de la segunda pertenece a uno de la primera. Ejemplo: una carrera tiene muchas materias.
  • Muchos a muchos (M:N): varios registros de una tabla pueden relacionarse con varios de la otra. Ejemplo: un estudiante cursa varias materias y cada materia tiene varios estudiantes.

Para representar una relación M:N se usa una tabla intermedia (también llamada tabla de unión). Guarda las claves foráneas de las dos tablas relacionadas. Así, una tabla inscripciones puede conectar estudiantes con materias y representar cada inscripción.

¿Cómo se conecta una aplicación a una base de datos?

En un sitio web, el navegador muestra la página y envía solicitudes al servidor de la aplicación (backend). El backend valida la solicitud y usa un conector o controlador de base de datos para comunicarse con la base de datos. Luego devuelve al navegador solo la información necesaria.

El conector es el componente que permite al backend hablar el protocolo de la base de datos elegida. Las credenciales de acceso se guardan de forma segura en el servidor; no se ponen en el código visible del navegador. Las claves primarias y foráneas, por su parte, conectan los registros entre las tablas.

Navegador
    ↓ solicitud
Backend de la aplicación
    ↓ conector de base de datos
Base de datos
    ↑ resultados

Ejercicio: base de datos para una escuela

Una escuela desea tener una base de datos que almacene los datos principales de cada estudiante, la carrera que estudia, las materias que cursa y los profesores que le imparten clase. También desea llevar un registro de las materias que imparte cada profesor.

  1. Identifica las entidades y los datos principales que debería guardar cada una.
  2. Decide cómo se relacionan: considera las relaciones 1:1, 1:N y M:N, y determina dónde hace falta una tabla intermedia.
  3. Dibuja un diagrama entidad-relación que muestre las tablas y sus relaciones.
  4. Diseña las tablas en MySQL, incluyendo una clave primaria para identificar cada registro y claves foráneas para conectar las tablas.

Por ahora, analiza el problema y diseña la solución en papel. La creación de las tablas y la práctica en MySQL se harán más adelante.
