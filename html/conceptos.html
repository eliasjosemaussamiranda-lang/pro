Primeros pasos para comenzar a programar

Antes de escribir código, vamos a crear una carpeta para guardar juntos los archivos de nuestro proyecto y abrir esa carpeta en Visual Studio Code (VS Code).

1. Crea una carpeta para tu proyecto

  1. Abre el Explorador de archivos de Windows. Puedes hacerlo con el atajo Windows + E.
  2. Entra en un lugar fácil de encontrar, como la carpeta Documentos.
  3. Haz clic derecho en un espacio vacío y selecciona Nuevo → Carpeta. También puedes usar Ctrl + Shift + N.
  4. Escribe un nombre sencillo, por ejemplo mi-primer-sitio, y presiona Enter.

Esta carpeta será el lugar donde guardaremos todos los archivos del sitio. Puedes usar otro nombre, pero evita nombres difíciles de reconocer.

2. Abre la carpeta en Visual Studio Code

  1. Abre Visual Studio Code desde el menú Inicio de Windows.
  2. En la parte superior, selecciona Archivo → Abrir carpeta... (en inglés, File → Open Folder...).
  3. En la ventana que aparece, busca Documentos y selecciona la carpeta mi-primer-sitio que acabas de crear. Selecciona la carpeta, no un archivo dentro de ella.
  4. Presiona Seleccionar carpeta para abrirla en VS Code.
  5. Si VS Code pregunta si confías en los archivos de esa carpeta y la creaste tú, confirma que confías para continuar.

La carpeta aparecerá en el panel Explorador, a la izquierda. Cuando creemos archivos para el proyecto, aparecerán allí y quedarán guardados dentro de esa carpeta.

Si no ves el panel, abre el menú Ver → Explorador o presiona Ctrl + Shift + E.

Conceptos

Vamos a entender para qué sirve cada tecnología antes de combinarlas.

¿Qué es HTML?

HTML significa HyperText Markup Language. es un lenguaje que sirve para organizar el contenido de una página web. Le indica al navegador qué parte es un título, un párrafo, una imagen, un enlace o una lista.

HTML es como el esqueleto de una página web, porque organiza y sostiene todas sus partes..

¿Qué es CSS?

CSS se ocupa de la apariencia. Con CSS podemos cambiar colores, tamaños, espacios, bordes, fondos, fuentes y la distribución de la página.

.titulo {
  color: blue;
  font-size: 40px;
}

crea un título y con CSS decide cómo se verá.

¿Y JavaScript?

JavaScript agrega comportamiento e interactividad: puede responder a botones, cambiar textos, mostrar mensajes y hacer cálculos.

function saludar() {
  alert("Hola");
}

Más adelante aprenderemos a organizarlo en su propio archivo.

¿Cómo trabajan juntos?

HTML construye la estructura, CSS define la apariencia y JavaScript añade interacción. Juntos permiten crear sitios web completos.
