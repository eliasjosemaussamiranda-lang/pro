Etiquetas en CSS

CSS no usa etiquetas HTML: usa reglas para cambiar la apariencia de los elementos HTML. Cada regla combina un selector, que elige qué cambiar, con propiedades y valores que indican cómo se verá.

Cómo se escribe una regla CSS

El selector va antes de las llaves. Dentro de ellas, cada declaración tiene una propiedad, dos puntos, un valor y, normalmente, un punto y coma. En este ejemplo, la regla cambia el color del título principal.

h1 {
  color: darkgreen;
}

h1 selecciona los títulos principales; color es la propiedad y darkgreen su valor. Las llaves agrupan las instrucciones de la regla.

Selectores: a qué elemento aplicar estilos

Un selector de etiqueta, como p, afecta a todos los párrafos. Para seleccionar un atributo class, escribe un punto antes del nombre. Para seleccionar un id, escribe #. Las clases se pueden compartir; usa cada id una sola vez por página.

p {
  color: #333333;
}

.aviso {
  background-color: lightyellow;
}

#titulo-principal {
  color: navy;
}

Estas reglas dan color a todos los párrafos, ponen un fondo claro a los elementos con class="aviso" y cambian el color del elemento con id="titulo-principal".

Colores y fondos

color cambia el color del texto y background-color cambia el fondo. Puedes escribir colores por nombre, como tomato, o usar códigos hexadecimales, como #2457a7.

.boton-comprar {
  color: white;
  background-color: #2457a7;
}

Al aplicar esa clase a un botón, el texto queda blanco sobre un fondo azul. Comprueba que haya suficiente contraste para que se pueda leer.

Texto y tamaños

font-size controla el tamaño del texto y font-weight su grosor. Puedes usar unidades como px o rem; rem ayuda a mantener tamaños que se adaptan a las preferencias del navegador.

.receta-titulo {
  font-size: 2rem;
  font-weight: 700;
}

.receta-descripcion {
  line-height: 1.6;
}

El título se ve más grande y grueso; line-height deja espacio vertical entre las líneas de la descripción y facilita la lectura.

Espacio, bordes y esquinas

padding crea espacio dentro de un elemento, entre su contenido y el borde. margin crea espacio fuera del elemento. border dibuja un borde y border-radius redondea sus esquinas.

.tarjeta-receta {
  padding: 16px;
  margin: 12px 0;
  border: 1px solid #cccccc;
  border-radius: 8px;
}

La tarjeta tendrá espacio alrededor de su contenido, separación con lo que está fuera, un borde fino y esquinas redondeadas.

Usar CSS desde un archivo

Guarda las reglas en un archivo con extensión .css, por ejemplo estilos.css. Para conectarlo a una página HTML, agrega un elemento <link> dentro de <head>. La ruta debe coincidir con el lugar donde guardaste el archivo.

<head>
  <link rel="stylesheet" href="estilos.css">
</head>

Si el archivo CSS está dentro de una carpeta llamada css, usa una ruta como css/estilos.css.
