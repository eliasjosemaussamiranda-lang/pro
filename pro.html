Aprender HTML desde cero.

Para hacer cualquier cosa en HTML, se debe abrir una etiqueta con < > en el mismo orden, quedando como < nombre >, y luego cerrarla con </nombre>.

Conocimientos previos

Etiquetas básicas

Las etiquetas se usan para definir estructura y contenido. La mayoría se escriben dentro de signos < > y necesitan cierre.

Orden y cierre

Es importante abrir una etiqueta y cerrarla en el orden correcto. Si no se cierra, el navegador puede interpretar el contenido de forma incorrecta.

Semántica

Las etiquetas ayudan a organizar el contenido del sitio, como títulos, párrafos, listas y bloques importantes.

Estilo y presentación

Con CSS se pueden controlar colores, tamaños, alineación y diseño general de la página.

Etiquetas más usadas

  1. h1, h2, h3...: Se usan para crear títulos. h1 es el más importante y el resto son subtítulos.
  2. p: Define un párrafo.
  3. img: Inserta una imagen.
  4. ol: Crea una lista ordenada.
  5. li: Define cada elemento de la lista.
  6. b e i: Dan formato en negrita e itálica.

Ejemplo sencillo

<h1>Bienvenido</h1>
<p>Este es un párrafo con texto importante.</p>
<ol>
  <li>HTML</li>
  <li>CSS</li>
</ol>
