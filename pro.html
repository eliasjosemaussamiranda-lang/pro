¿Dónde puedes conseguir Visual Studio Code?

Visual Studio Code (VS Code) es gratis. Puedes descargarlo desde su página oficial de descarga. Está disponible para: Windows, Linux y macOS.

¿qué vamos a usar?

usamos VS Code porque es una herramienta que puede sugerir y completar código mientras trabajamos. Lo importante es entender lo que escribimos. no copiar sugerencias sin saber qué hacen, en VS Code usamos lengiajes de programacion como HTML, CSS y JavaScript para crear paginas web.

HTML

La estructura y el contenido de la página, en otras palabras HTML es el cuerpo de la página.

CSS

La apariencia, los colores y la distribución, en otras palabras css es el estilo de la página.

JavaScript

El comportamiento y la interactividad, en otras palabras JavaScript son los músculos y los sentidos.

¿Qué necesitamos?

Un computador, un navegador, VS Code y ganas de probar y equivocarnos.

Programar también es probar, encontrar errores y volver a intentarlo. Un error no significa que seas malo: es una pista de lo que todavía podemos aprender.
