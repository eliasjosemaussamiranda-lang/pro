Conceptos Etiquetas Ejemplo

Conocimientos previos

Ideas importantes para empezar a construir una página web con HTML y CSS.

Etiquetas básicas

Las etiquetas definen la estructura y el contenido de una página. Se escriben entre signos < >.

Orden y cierre

Muchas etiquetas tienen una apertura y un cierre. Por ejemplo: <p>Texto</p>. Ciérralas en el orden correcto.

Semántica

Usa etiquetas que describan el contenido, como títulos, párrafos, listas y secciones. Así el documento resulta más claro.

Estilo y presentación

CSS permite cambiar colores, tamaños, espacios y distribución visual sin mezclar el diseño con el contenido HTML.
