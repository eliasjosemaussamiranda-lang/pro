Conceptos básicos

Vamos a entender para qué sirve cada tecnología antes de combinarlas.

¿Qué es HTML?

HTML significa HyperText Markup Language. Es un lenguaje de marcado que organiza el contenido y le indica al navegador qué es un título, párrafo, imagen, enlace o lista.

HTML crea la estructura, pero no se encarga principalmente de que la página se vea bonita.

¿Qué es CSS?

CSS se ocupa de la apariencia. Con CSS podemos cambiar colores, tamaños, espacios, bordes, fondos, fuentes y la distribución de la página.

.titulo {
  color: blue;
  font-size: 40px;
}

crea un título y con CSS decide cómo se verá.

¿Y JavaScript?

JavaScript agrega comportamiento e interactividad: puede responder a botones, cambiar textos, mostrar mensajes y hacer cálculos.

function saludar() {
  alert("Hola");
}

Más adelante aprenderemos a organizarlo en su propio archivo.

¿Cómo trabajan juntos?

HTML construye la estructura, CSS define la apariencia y JavaScript añade interacción. Juntos permiten crear sitios web completos.

Class e id

Una class puede agrupar varios elementos que comparten un estilo. Un id normalmente identifica un elemento específico.

<p class="importante">Un texto importante</p>
<p class="importante">Otro texto importante</p>
<h1 id="titulo">Mi página</h1>

Piensa en class como un grupo y en id como una identificación individual. En CSS se seleccionan con .importante y #titulo.
